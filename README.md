# ngeWARteg

Platform voucher diskon makanan sisa warteg dan UMKM. Capstone Project Kelompok 3, Universitas Bakrie.

## Struktur

- `frontend/` : antarmuka web (HTML, CSS, JavaScript tanpa framework). Buka `frontend/index.html` di browser.
- `backend/` : API Node.js/Express (mulai Minggu 7).
- `database/` : `schema.sql` dan `seed.sql` (mulai Minggu 7).
- `docs/` : API contract dan koleksi Postman.

## Menjalankan frontend (sementara, tanpa backend)

Buka `frontend/index.html`. Data masih contoh dan tersimpan di browser.

Akun demo (kata sandi `12345678`): `ghefa@gmail.com` (pembeli), `bahari@merchant.com` (merchant), `ghefa@admin.com` (admin, tambahkan `#admin` di alamat).
